Psychometrics — The Analytic Moat

Build in progress — IRT layer, summer 2026

A decade of EMS testing has produced a deep response corpus that almost no competitor holds: per-question correctness plus the selected option, a mandatory continuous confidence signal, a real student→school→instructor→cohort hierarchy, and recent per-item timing. The honest gap: today’s “adaptive” exam is domain-mastery proficiency with random selection — not real IRT. A credentialed psychometrics intern is building the calibration layer this summer: 1PL bank-wide, 2PL where data supports, item-quality and distractor flagging, then a real CAT for the CE/CAPCE product.

🧬 Why This Is a MoatDistinctively possible here — not generic test-bank features ▾
Internal capability — not outward marketing
This page documents an internal analytic asset: what the data can measure and what is being built on top of it. The psychometric machinery (IRT calibration, the confidence signal, the multilevel hierarchy, the AI item-quality loop) is the moat precisely because it stays under the hood. The outward story is “evidence-based,” not the backend mechanics. Treat everything here as capability / portfolio documentation.
Three Things Almost No Competitor Has
  • The confidence signal. A mandatory, continuous 1–100 self-rating on every quiz/unit/exit response — ~1.6M of them. Enables genuine confidence-accuracy calibration and the “confident-and-wrong on an airway item” clinical-safety quadrant.
  • The institutional hierarchy. A real student → school → branch → instructor → cohort FK tree, spanning 239 programs in 30+ states — the substrate for multilevel and value-added modeling no generic bank can build.
  • The selected option. We store which wrong answer was chosen, not just right/wrong — turning every response into full distractor-trace data that feeds the AI item generator.
The Honest Gap Being Closed
  • Current “Adaptive” exam is domain-mastery proficiency with random selection — no theta, no item information, no true adaptivity.
  • No item statistics are persisted — difficulty / discrimination / IRT parameters are computed ad hoc (in UnitExamStudentService.php) and never saved.
  • Matched NREMT outcomes sit at ~225 — fine for descriptive validity, too thin to anchor heavy prediction.
  • The summer build replaces random selection with a calibrated bank and a real CAT (theta + max-information selection + stopping rules).
📡 What the Data Can MeasureHigh-signal assets present in the response corpus today ▾
✅ Correctness + Selected Option
Per-response correctness and the chosen option text across the legacy banks (Quiz, Simulator, Unit, Exit). Stored as option text matched back to questions.option_1..6; Adaptive uses normalized option IDs. This is the IRT calibration matrix and the distractor-analysis input.
Have now
🎯 Continuous Confidence (1–100)
A mandatory per-question 1–100 slider stored raw as confidence_level_range on Quiz/Unit/Exit. The High/Med/Low enum (1–29 / 30–70 / 71+) is only a derived instructor label. Enables Brier curves and continuous over/under-confidence — absent on Simulator/EOPA/Adaptive; entry is client-side-only, so filter > 0.
Have now
🏛 Institutional Hierarchy
A real student → school → branch → instructor → group/cohort tree via users.school_id / school_branch_id / instructor_id and group_students. Caveat: membership changes over time — use user_school_transfer_histories for time-correct cluster assignment.
Have now
⏱ Per-Item Timing & Position
Duration and question_number from *_time_logs enable rapid-guessing / non-effort filters, order effects, and within-attempt fatigue. Recent-only: timing migrations land Feb 2026, so the historical bulk has a blind spot — clean only on post-Feb-2026 data.
Have now (recent)
📈 Longitudinal Signal
Exam-level progression EMT→AEMT→Paramedic (user_exam_level_histories), retakes (adaptive_exam_retake_requests), and cross-bank linkage via shared user_id — one unified per-student record spanning every bank, for learning curves and decay modeling.
Derivable
📏 Item-Exposure Counts
COUNT(*) GROUP BY question_id over the response tables sets the per-item N. This threshold decides which items support 1PL vs 2PL calibration — the practical gate on the entire build, given a sparse per-item bank.
Derivable
The 60-Second Picture
Richest data: legacy response records — per-question correctness, selected-option text, category/objective tags — joined to the institutional hierarchy. Thinnest watch-outs: no item statistics stored, timing recent-only, confidence bank-limited (none on EOPA/Adaptive), NREMT sparse + manual, Bloom’s absent, demographics = DOB + gender only. The anonymized export Brad works from (anon_GA_combined_question_report.csv, ~308K rows) is a person × item × correct matrix — calibration-ready on day one.
📐 The IRT Calibration BuildThe spine — everything downstream consumes these parameters ▾
1
IRT Parameter Estimation — the spine (W6)
1PL across the production bank; 2PL where response volume supports it. No full 3PL across all ~10,600 items — sparse items are excluded by design, and partial pooling over the hierarchy (W20) is the principled answer to thin per-item N, not guessing-parameter models. Calibrate on Exit + Unit Exam first (consistent stakes); treat Targeted Quiz as a metacognition signal, not a calibration input, since voluntary low-stakes effort biases difficulty. No persisted parameters exist anywhere — this is a pure from-scratch build in R / mirt / rstan, with nothing to validate against.
2
Item Quality & Distractor Analysis — falls out of #1 (W2, W7, W11)
Because the bank stores the selected option, every response becomes distractor-trace data: which wrong answers attract whom, dead distractors, distractors that lure high-ability students, and keys that underperform a distractor. Layered with Rasch fit statistics (infit/outfit + point-biserial), this makes 20k+ items human-reviewable and is the cheapest keying-failure detector. The resulting item-quality rubric feeds the AI question generator — closing a generate→vet→improve loop no prep shop has. (Persisting the grade back to the bank is the one piece needing a new migration.)
3
CAT Formalization — deploy in CE/CAPCE, not main mededprep.com (W16)
Build a real adaptive test on the calibrated bank: EAP theta estimation + maximum-information item selection + stopping rules. CE is the right target — new build, lower-stakes than NREMT, current business priority. The engine is derivable from a calibrated bank; a live test additionally needs new SE/theta/exposure logging columns in the runtime, plus an exposure/retirement ledger (W23) as the safety prerequisite before any CAT goes live.
Calibration Ground Rules
Separate the streams (Exit + Unit first; Targeted Quiz is metacognition, not calibration). 1PL bank-wide, 2PL where data is rich, no 3PL-across-everything. Exclude very-low-N items. NREMT outcomes (~225) are fine for descriptive validity but too thin to make prediction a centerpiece — don’t over-promise on it.

Top 5 Bets — High Value AND Confirmed Feasible
These five clear both bars: distinctive value, and both feasibility passes confirm the data exists today. Start here.
W1 · Confidence-Accuracy Calibration Engine
Confident-and-right vs. confident-and-wrong, per item / student / cohort. The continuous 1–100 signal makes this genuine Brier-curve calibration — the EMS clinical-safety story competitors can’t tell.
W2 · Full Distractor / Option-Trace Analysis
The single strongest under-used signal in the bank. Raw selection rates available now; the “high-ability picks the distractor” cut needs theta from W6. Feeds the AI generator and remediation.
W4 · Confidence-Keyed Miskey Detector
Items where high-confidence responses are systematically wrong → probable miskeys / ambiguous stems. Needs no IRT, so it works even where per-item N is too thin to calibrate.
W9 + W10 · Program/Instructor Value-Added
Shrinkage-adjusted value-added over the real FK hierarchy, paired with incoming-ability adjustment so it doesn’t punish programs serving weaker-entering students. Most distinctive institutional asset.
W15 · Cohort & State Benchmarking Reports
“How do my students compare?” is the #1 program-director ask, and 239 programs / 30+ states make it meaningful. The most directly sellable artifact — and the natural payload of the NREMT acquisition calls. Honest label: “national” is internal-bank-relative, not externally normed.

🧠 Metacognition Research ThreadThe confidence signal as a publication-track asset ▾
A Remarkable Mandatory Metacognition Dataset
Students self-rate every quiz/unit/exit question on a mandatory continuous 1–100 confidence slider. Across ~1.6M responses, that is a per-question metacognition corpus essentially no competitor holds — because almost none capture confidence at all. It upgrades the calibration work from coarse calibration-by-bucket to genuine continuous calibration: Brier curves and continuous over/under-confidence indices.
What the Research Lane Builds
  • Rerun the metacognition analyses with updated categorizations (TQZ + the continuous confidence signal)
  • The confident-and-wrong quadrant — the EMS clinical-safety angle (e.g. confident-wrong on an airway item)
  • Confidence-weighted targeted remediation queue (W5) on the existing Targeted Quiz surface
  • Design the psychometric gating for AI-generated items
  • Publication-track output under Brad’s byline — the “evidence-based” sales + CAPCE-accreditation asset
Confidence-Signal Caveats (Carry Into Every Analysis)
  • Stored raw as confidence_level_range; the High/Med/Low enum is only a derived instructor label
  • Captured on Quiz / Unit / Exit only — absent on Simulator / EOPA / Adaptive
  • Mandatory entry is client-side-only — filter confidence_level_range > 0 and quantify missingness before reporting
  • A confidence-aware CAT stopping rule is blocked until Adaptive captures confidence (needs new capture)
⚠ Honest ConstraintsDegradations to respect, not blockers to hide ▾
⚠ Set Expectations Honestly
Neither feasibility pass found a single item that is outright not-feasible — the binding limits are degradations, not walls. Listed here so nobody over-promises.
NREMT matched outcomes ≈ 225 Binding
The criterion of record is NREMT pass/fail, but only ~225 individually-matched outcomes exist today — low power for item-level prediction. Good for descriptive validity; too thin to make prediction a centerpiece. nremt_attempts also has no FK, no attempt number, no exam date, and a 'RECYCLED ' enum with a literal trailing space.
The lever (W17): Brad — a credentialed psychometrician with a company email — runs a day-one collection campaign across the 239 programs under a lightweight MOU/consent, growing N toward 800–1,500. Insist on individual-matched outcomes (aggregate program pass rates are far weaker), and fix the schema while building the pipeline. The same calls warm the accounts we later sell reporting to.
No stored item statistics Build-from-scratch
No difficulty / discrimination / IRT parameters are persisted anywhere — discrimination is computed ad hoc in UnitExamStudentService.php and never saved. Everything is built from raw responses, with nothing pre-existing to validate against.
Sparse per-item N → calibration exclusions Scope
Median item exposure is modest and many items are sparse. 1PL bank-wide, 2PL where data supports, no full 3PL across all items. Very-low-N items are excluded for now; partial pooling over the hierarchy (W20) is the principled answer to sparse N — not guessing-parameter models.
Timing is recent-only (Feb 2026) Blind spot
The *_time_logs tables only exist post-Feb-2026, so speededness / rapid-guessing / fatigue models have a large historical blind spot. The historical bulk cannot be retroactively cleaned for non-effort — timing filters apply to recent data only.
Other capture limits — named honestly Label
Confidence is absent on EOPA/Adaptive (blocks a confidence-aware CAT stop). Demographics are DOB + gender only — protected-class fairness DIF is capture-limited, so stay with curricular DIF framing. Bloom’s taxonomy is absent. Text-match option keying has an early-data failure tail (quantify the NULL-key rate and exclude the tail). Mid-attempt answer changes are deleted, so the historical “vacillation” path isn’t recoverable. And benchmarking “national” distributions are internal-bank-relative, not externally normed — label as such.
