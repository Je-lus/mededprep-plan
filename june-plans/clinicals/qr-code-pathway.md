# Generic QR Code Pathway

**Priority:** P2
**Touches:** clinicals.mededprep.com

## Problem

Currently QR codes on clinicals are student-specific. We need a second pathway where schools get generic, reusable cards.

## Proposed Solution

- School receives generic cards (like a dot card or hotel room key)
- Each card has a card number
- School assigns a card to a student through the clinical system
- Only one student can be assigned to a card at a time
- Cards are reassignable — when a student finishes, the card can be assigned to a new student
- Need a card management UI (reader/hotel-room-key-style interface) for programs to:
  - Assign card to student
  - Unassign card from student
  - View card assignment history
