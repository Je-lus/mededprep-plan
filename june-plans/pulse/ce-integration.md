# Pulse CE Integration

**Priority:** P2
**Touches:** Pulse — routing, UX, framing

## Problem

We need to add continuing education into Pulse without disrupting the existing games experience. We are NOT calling it "Pulse CE" as a separate product — it's all Pulse, just with a CE pathway.

## Open Design Questions

- How does the user indicate they're here for CE vs. games?
- Options discussed:
  - "Are you here for the games?" prompt
  - A toggle/switch: "I'm here to do continuing education" vs. "I'm here to play games"
  - Something more subtle?
- How to keep the existing Pulse experience exactly the same for game users
- Where does the CE layer live in the navigation?
- How do the two experiences share or diverge from each other?

## Framing Matters

The exact UX framing is important. This isn't just a feature toggle — it's how we introduce an entirely new use case into an existing product without confusing current users.

## Status

Not started — needs design exploration before implementation.
