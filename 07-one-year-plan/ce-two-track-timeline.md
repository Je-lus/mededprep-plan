# CE Initiative: Two-Track Launch Timeline

> **Note:** This two-track framing is superseded by Richard's three-pathway model (see richard-vision.html). Retained as structural reference.

---

## The Two-Track Thesis

MedEdPrep's CE launch runs two production tracks in parallel. Track 1 (assessment-only) gets revenue flowing within days of CAPCE accreditation. Track 2 (content CE) builds the full product experience over the following months. Both tracks feed into Richard's combined Pathway 3 once content is available.

This structure means MedEdPrep never waits. The item bank is the product on Day 1. Video and reading modules layer in as they ship.

---

## Track 1: Assessment-Only CE (Fast Track)

**Why it ships first:** No video production, no editing pipeline, no SME studio scheduling. The 10,600+ calibrated item bank already exists. CAPCE has confirmed assessment-only CE is allowed. A 30-question adaptive exam with rationales produces ~20,700 characters — 2.8x the 0.25 CEH minimum.

### Timeline

| Milestone | Target |
|---|---|
| CAPCE organizational accreditation finalized | Imminent (May 2026) |
| Item-to-topic mapping complete (tag items for CE topic coverage) | Day 0 + 7 |
| Assessment delivery system built (adaptive exam + remediation loop + timer enforcement + certificate generation) | Day 0 + 7 |
| CAPCE auto-reporting integration wired | Day 0 + 14 |
| First assessment-only CE courses live | Day 0 + 7 |
| 5-10 assessment-only courses published | Day 0 + 30 |

### Key Dependencies

- CAPCE organizational accreditation (hard gate)
- Item bank topic tagging (which items map to which CE learning objectives)
- Timer enforcement (CAPCE requires learners spend allotted time)
- Certificate generation system
- CAPCE activity reporting API integration (endpoint available only after accreditation)
- 70% passing threshold with unlimited retakes using different questions
- Remediation loop: forced rationale reading + follow-up verification question on wrong answers

### What Ships

- 0.5 CEH courses: 15-20 adaptive questions (~30 minutes)
- 1.0 CEH courses: 45 adaptive questions (~60 minutes)
- Diagnostic competency report mapping to NES, NSOP, NMG, and NCCP standards
- Fail < 70% triggers remediation gate (must complete Pathway 2 resources before retake — once available; until then, retake with different questions)

## Track 2: Content CE (Slower Track)

**Why it takes longer:** Video production, SME recording sessions, editing (Sydney on DaVinci Resolve), script development, CAPCE character count compliance documentation. None of these are blockers — the infrastructure exists and the team is ready — but the production cycle is inherently sequential.

### Timeline

| Milestone | Target |
|---|---|
| Content production pipeline setup (SME scheduling, script templates, studio prep) | Day 0 - 14 (pre-accreditation) |
| First SME recording sessions | Day 0 + 7 |
| First video courses through editing pipeline | Day 0 + 21 |
| First content CE courses published (15-min micromodules, 0.25 CEH) | Day 0 + 60 |
| Content catalog reaches 10+ courses | Day 0 + 90 |

### Key Dependencies

- SME availability: 5-6 SMEs, rotating 3+ days/week in studio
- Sydney's editing pipeline: 15-min module = ~1 hour editing, 48-hour typical turnaround
- Script development and SME review
- CAPCE character count documentation (~7,500 chars = 0.5 CEH; ~15,000 chars = 1.0 CEH)
- Post-test development for each content module (15-question post-test at 70% passing)
- Conflict of interest disclosures per CAPCE requirements
- Learning objectives mapped to content for each module

### What Ships

- 15-minute video micromodules (0.25 CEH base unit)
- 30-minute video modules (0.5 CEH)
- Text-based study guides (reading material with character count compliance)
- Post-test assessments paired with each content module
- Content maps directly to Track 1 exam topics (razor/blade model)

### Production Capacity (Not a Bottleneck)

- 4 Lumix cameras, professional studio, multi-angle capability
- $6K DaVinci Resolve editing rig, Sydney's workspace at MedEdPrep office
- 3-4 hours of content per recording day, 5-6 hours on focused days
- 15-min module editing: ~1 hour; 30-min module: ~2 hours
- Same-day turnaround possible for short pieces; 48-hour typical

## Combined Timeline: Month-by-Month

All dates relative to CAPCE accreditation approval (Day 0).

### Month 1 (Day 0 - 30)

**Track 1:** First assessment-only courses go live within the first week. Item mapping sprints tag existing bank for CE topic areas. Target 5-10 assessment-only courses published by end of month. Revenue begins.

**Track 2:** Content production pipeline activates. SMEs begin recording first modules. Scripts and learning objectives finalized for initial batch. Editing pipeline running.

**Combined:** Platform infrastructure ships — certificate generation, CAPCE auto-reporting, timer enforcement, diagnostic reports.

### Month 2-3 (Day 30 - 90)

**Track 1:** Assessment catalog expands. Pediatric topics prioritized (Georgia requires 8 pediatric CE hours). Cardiovascular modules added. Diagnostic reports refined based on early user feedback.

**Track 2:** First video content courses ship (Day 60-90). 15-minute micromodules first, then 30-minute modules. Text-based study guides begin publishing.

**Combined:** Pathway 3 (combined assessment + content) becomes available as content modules map to assessment topics. Agency pilot conversations begin with warm contacts (Richard, Heather, Dr. Tim Thomas all have agency relationships).

### Month 3-6 (Day 90 - 180)

**Track 1:** Assessment catalog covers majority of NCCP National Component topics. Georgia-specific coverage complete (pediatric hours, state requirements).

**Track 2:** Steady content production — multiple new modules per week. SME rotation keeps studio running 3+ days/week.

**Combined:** Agency pilot programs launch. B2B pricing validated. Agency dashboard development begins if 3-contract decision gate is met. AHA Guidelines module ships as free lead magnet.

### Month 6-9 (Day 180 - 270)

**Track 1:** Full NCCP National Component coverage target reached. Assessment courses cover all required recertification domains.

**Track 2:** Deep content library — 50+ video/reading modules across all major EMS topics.

**Combined:** Agency dashboard live (diagnostic data per employee, compliance tracking, gap analysis). B2B sales in active motion. Heather running national sales. Richard + Samantha + Dr. Tim Thomas leveraging agency relationships.

### Month 9-12 (Day 270 - 365)

**Track 1:** Additional certification level support (AEMT, EMT — beyond paramedic). Adaptive engine refined with CE-specific response data (IRT recalibration at 500+ CE responses).

**Track 2:** Premium content tiers. Specialty topics. Conference-ready showcase material.

**Combined:** Scale. National reach. Revenue engine running on both B2C individual sales and B2B agency contracts. Platform positioned for NREMT's shift toward competency-based recertification.

## Why Two Tracks Wins

The assessment-only track eliminates the traditional CE launch dependency: "we need content before we can sell anything." MedEdPrep's 10,600+ item bank with 1.55M responses IS content. It ships on Day 1.

Meanwhile, the content track builds toward the full vision — video modules, reading materials, combined pathways — without holding up revenue. Every content module that ships makes the assessment track more valuable (remediation resources for failed exams) and unlocks Pathway 3.

The result: fast market entry with a product no EMS CE competitor offers (adaptive assessment-only CE with diagnostic competency reports), building toward a complete continuing education platform that covers all three of Richard's pathways.
